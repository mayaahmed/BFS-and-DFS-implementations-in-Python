Each file in this directory is an independent python program and acts as building blocks for the two main programs bfs.py and dfs.py.


The bfs program gives a list of shortest paths and draws the bfs tree.

To run the bfs program, on the command line type:

python bfs.py filename source

Example:

python bfs.py graphsource_s.txt 's'


The DFS program draws the DFS forest and lists the parent, start time, and end time of each node.

To run the Dfs program, on the command line type:

python dfs.py filename 
Example:

python dfs.py bookeg.txt 

Reference:  T. H. Cormen, C. E. Leiserson, R. L. Rivest, and   C. Stein, Introduction to Algorithms, 4th ed.  Cambridge, MA, USA: MIT Press, 2022.
